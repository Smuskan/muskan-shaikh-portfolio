# Muskan Shaikh — Portfolio

**Thoughtful software, curious ideas, and a little anime-inspired energy.**

Welcome to my portfolio. I’m Muskan Shaikh, a software developer from Pune, India, with a background in Computer Engineering. This site is a snapshot of what I’ve been learning and building—because curiosity is great, but seeing the idea work is even better.

## What you’ll find

The portfolio brings together selected projects, technical skills, education, and experiences beyond code. Projects range from a flight price prediction web app and an Android learning platform to customer segmentation and shipment visibility. Each reflects my interest in turning practical problems into clear, useful software.

You can also explore my resume, learn about my internship and student leadership experience, and find links to my GitHub and LinkedIn profiles.

## Built with

HTML, CSS, and vanilla JavaScript. The site is static and can be opened locally by launching `index.html` in a browser. Keep `styles.css`, `script.js`, `resume.html`, and the `assets` folder alongside it so everything displays and works correctly.
