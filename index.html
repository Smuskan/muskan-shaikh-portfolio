PROJECT NOTES / FLIGHT PRICE PREDICTION

Making an estimate from a messy journey.

THE PROBLEM

Flight prices vary with route and trip details. This project explores how regression can turn those inputs into a useful estimate.

APPROACH

Python preprocessing and feature engineering feed a regression model, served through a Flask REST API and a responsive web interface.

TOOLS
